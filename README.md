# NeuraGen - AI Resume & Interview Cluster

NeuraGen is a full-stack application designed to generate AI-powered interview strategies and help users optimize their professional profiles for specific job opportunities.

## 📁 Project Structure

* **`frontend/`**: The client-side application built with **React**. Handles the UI, form management, and navigation using **React Router**.
* **`backend/`**: The server-side code built with **Node.js/Express**. Handles API requests, authentication routes, and AI-powered strategy generation.

## ✨ Features

* **Secure Authentication**: Uses **Passport.js** to handle user login and secure sessions.
* **Social Login**: Supports **Google OAuth** for quick and secure user access.
* **Custom Strategy Generation**: Analyzes target job descriptions against user resumes to build tailored interview plans.
* **Protected Routing**: Leverages **React Router** to ensure only authenticated users can access the interview generation dashboard.
